### `open` {: .unverified-section }

Opens a file.

```lua
file = io.open(filename, mode)
```

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `filename` | `string` | Yes | File path. |
| `mode` | `string` | Yes | Open mode. |

| Return | Type | Description |
|--------|------|-------------|
| `file` | `file` | Open file handle. |
