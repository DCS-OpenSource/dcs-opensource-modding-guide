    getTemperatureAndPressureAtPoint#

    Returns temperature and pressure at a point.

    temperature, pressure = Weather.getTemperatureAndPressureAtPoint(pos)

    Note

    pos is expected to be shaped like { position = { x = 0, y = 0, z = 0 } }.
